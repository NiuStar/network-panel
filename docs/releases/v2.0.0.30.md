# Network Panel v2.0.0.30

## 更新

- 节点 `install.sh -p 4` 的默认 GitHub 加速代理改为 `https://proxy.yjkj02.com/`；`-m cn` 复用同一默认地址。
- 新增 `--proxy URL` / `--proxy=URL`，支持自定义 GitHub 加速 URL 前缀、自动补齐末尾 `/`，且优先于 `-p`，不受参数顺序影响。
- 新增 `-4` / `-6` 简写，保留 `-p 4` / `-p 6`、原有短参数及下载源回退行为。
- 增加帮助、参数错误校验及 11 项回归测试；自定义代理通过真实 curl 的本地 HTTP API/文件请求验证。
- 后端及两种 Agent 的版本统一为 `2.0.0.30`。补齐标签触发的完整二进制、前端、安装脚本、源码和 SHA256SUMS 发布流程。

## 使用

```bash
bash install.sh -a 面板地址:端口 -s 节点密钥 -p 4
bash install.sh -a 面板地址:端口 -s 节点密钥 --proxy https://your-proxy.example/
```

`--proxy` 是 GitHub 加速 URL 前缀，不是系统 HTTP/SOCKS 代理。显式配置代理时 GitHub 请求只走代理；面板及静态源仍按原模式参与回退。不传代理参数的默认直连行为不变。
